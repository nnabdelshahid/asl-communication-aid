# Project Context

- **Project:** ASL Communication Aid
- **Owner:** Nader Abdelshahid
- **Canonical repository:** `nnabdelshahid/asl-communication-aid`
- **Visibility:** Public
- **Purpose:** Experimental, browser-based accessibility communication aid.
- **Major architecture:** React/Vite web application using MediaPipe hand landmarks, a local limited rule classifier, sentence state, practice/settings UI, and GitHub Pages-compatible deployment.
- **Verified implementation:** Current documentation and source identify a limited set of signs such as A, L, and V plus local sentence/practice interactions.
- **Boundaries:** This is a prototype, not a complete ASL translator, interpreter replacement, or full ASL grammar/gesture system.
- **Security/privacy:** Prefer local camera processing, request camera permission clearly, avoid retaining imagery, and keep public docs accurate and respectful.
- **Relationships:** Independent accessibility experiment; it must not be presented as production translation capability.
- **Cost principle:** Browser-local and static-hostable implementation minimizes infrastructure and preserves portability.
- **Known TODOs:** Improve accessibility testing and expand recognition only with representative validation and careful scope language.

Actual source code takes precedence over outdated documentation.
