# ASL Communication Aid

## Overview
ASL Communication Aid is a cross-platform application (mobile and web) designed to bridge communication gaps for deaf and hard-of-hearing individuals using American Sign Language (ASL).

## Features

### 1. AI-Powered ASL Recognition
- Uses the device's camera to detect and interpret American Sign Language gestures in real-time.
- Converts recognized ASL signs into text and synthesized speech for verbal communication.

### 2. AI Avatar for ASL Closed Captioning
- Displays an AI-rendered human avatar that translates spoken or written text into ASL.
- Enhances video content and real-time communication accessibility.

### 3. Bidirectional Communication
- Enables seamless two-way communication between ASL users and non-signers.
- Supports text-to-speech and speech-to-text for comprehensive accessibility.

### 4. Cross-Platform Support
- **Mobile App**: Available for Android and iOS devices.
- **Web App**: Accessible via modern web browsers with camera support.

## Tech Stack

### Frontend
- **Mobile**: Flutter / React Native
- **Web**: React.js

### Backend
- Node.js / Django / Flask
- Firebase / AWS for data storage

### Machine Learning
- TensorFlow / PyTorch for ASL gesture recognition
- Google Cloud Speech-to-Text / OpenAI Whisper for speech processing
- AI Avatar rendering using Unreal Engine Metahuman or similar tools
